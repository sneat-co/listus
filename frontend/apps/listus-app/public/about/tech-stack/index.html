Inside Listus

The technology behind Listus

A tech stack is the languages, libraries and services used to build a product. Listus keeps shared lists and tasks in the same Sneat platform spaces where people already work together.

The app

Angular and Ionic provide the signed-in interface. Listus uses the Sneat platform's shared account, navigation and space components, then adds its own screens for lists and items.

The service

The Listus extension has a Go backend for list and task operations. Its records are scoped to a Sneat platform space, so a list belongs to the people and context that use it.

This website

The app is built into static browser assets. This public explanation is a small HTML page included with the app build and served by the current Firebase Hosting setup.

Related projects

Listus source contains the extension and standalone app. The Sneat platform supplies the shared services.
